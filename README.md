# yuri

> yuri straight in your terminal!
---
## requirements

| dependency | why | required? |
|---|---|---|
| Python ≥ 3.9 | gee i wonder | yes |
| [mpv](https://mpv.io/) | anime playback | for `watch` |

---

## usage

```
yuri read <name>              read manga/ln
yuri watch <name>             watch anime 
```

### example

```sh
yuri read "Adachi and Shimamura"
yuri watch "i'm in love with the villainess"
```


---

## sources

| type | source |
|---|---|
| manga | [MangaDex](https://mangadex.org/), [Dynasty Scans](https://dynasty-scans.com/) |
| light novel | [Dynasty Reader](https://dynasty-scans.com/) |
| anime | [AllAnime](https://allanime.to/), [Zen API / AnixPlay](https://anixplay.buzz/) |
